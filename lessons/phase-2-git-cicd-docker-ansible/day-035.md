## Cumulative quiz (10 Qs spanning Days 31–34)
1. What are the three object types a commit chain is built from, and how do they nest?
2. What does `HEAD` point to, and how does that change during a rebase?
3. `git diff` vs `git diff --staged` — what is each comparing?
4. Fast-forward merge vs three-way merge — what determines which one Git performs?
5. Walk through resolving a conflict: what do the three marker sections mean and what
   are the next two commands after editing the file?
6. What does `git stash pop` do that `git stash apply` doesn't?
7. `git fetch` vs `git pull` — what's the safer default habit and why?
8. Why must you never rebase a branch that others have already pulled?
9. `git reset --soft` vs `--mixed` vs `--hard` — what does each preserve or destroy?
10. Lightweight tag vs annotated tag — which one is preferred for a release, and why?
