2. What's the difference between the `command` and `shell` modules?
3. What condition causes a handler to actually execute, and why run at play-end?
4. `defaults/main.yml` vs `vars/main.yml` in a role — which wins, which is meant to be

5. Why is it safe to commit an `ansible-vault`-encrypted file but never the vault

   reporting?
8. What problem does the `pre-commit` framework solve versus raw `.git/hooks/` scripts?
9. Why must Makefile recipe lines use a tab, not spaces?
10. In SemVer, what's the difference between a MINOR and a PATCH bump?
