# Day 178 — Facilitator Script: Job Sprint

Phase 6 · follows Day 177 (capstone docs + demo video). Format: **facilitator
script**, not a technical lab — today is entirely about placement momentum.

---

## Session objective
Convert the finished capstone into an active job search: a polished resume, an
updated LinkedIn, and 20 real applications submitted, plus referral asks sent to
the instructor's and fresher's networks.

## Materials needed before the session
- Resume checkpoint #2 (Day 148) as the starting draft.
- The capstone repo, README, architecture diagram, and demo video (Day 177) —
  the primary new material to fold in.
- A running list of target companies/roles (fresher should arrive with this
  started, even roughly).

## Session outline (3h, time-blocked)

### Block 1 — Resume finalization (60 min)
- Walk the resume top to bottom against the finished capstone: does it name the
  specific stack (Kubernetes, Helm, ArgoCD, Terraform, Prometheus/Grafana, one ML
  component) with concrete outcomes, not just tool lists?
- Cut anything vague ("worked on cloud projects") and replace with the capstone's
  actual success criteria (SLOs met, chaos-tested, GitOps-managed) as bullet points.
- Confirm the GitHub repo link and demo video link are both on the resume and
  both actually work when clicked cold.
- Facilitator prompt: "If a recruiter has 6 seconds on this resume, what's the one
  line that gets you a callback?" — make sure that line exists and is near the top.

### Block 2 — LinkedIn rewrite (45 min)
- Headline: role-target-specific (e.g., "DevOps/SRE | Kubernetes, GitOps,
  Observability, MLOps-adjacent"), not a generic student title.
- About section: 3–4 sentences telling the capstone story (problem → what was
  built → what it demonstrates) — link the demo video.
- Post the capstone announcement publicly (this is the fresher's decision and
  action, not the facilitator's — confirm he's comfortable with the content and
  visibility before he publishes).
- Pin the capstone repo and 1–2 other strong repos from earlier phases.

### Block 3 — Applications + referrals (60 min)
- Target: 20 applications submitted today, prioritizing DevOps/SRE-titled roles
  (not MLOps-titled — per the phase's framing, ML is exposure, not the target job).
- For each application, spend under 5 minutes: tailor the resume's top bullet to
  the specific job description's language, submit, log it (company, role, date,
  link) in a tracking sheet.
- Draft 3–5 referral-ask messages (to the instructor's network, any contacts from the
  fresher's MCA program, LinkedIn connections at target companies) — **facilitator
  reviews drafts but the fresher sends them himself**; sending outward-facing
  messages is his action to own and confirm, not the facilitator's to send on his
  behalf.

### Block 4 — Wrap and log (15 min)
- Confirm: resume finalized, LinkedIn live, 20 applications logged, referral
  drafts ready to send (or sent, if he chose to).
- Note any gap surfaced today (a skill a job posting wanted that wasn't covered)
  for Day 179's mock-interview prep or Day 180's "what to learn next" map.

## Facilitator checklist (confirm before ending session)
- [ ] Resume includes capstone with concrete, evidenced bullets and working links.
- [ ] LinkedIn headline/about updated; capstone post published (fresher's own call).
- [ ] 20 applications logged with tracking-sheet entries.
- [ ] Referral messages drafted and reviewed.
