## Theory (1h)

### A. AWS Solutions Architect Associate — exam shape (15 min)
- Recall Day 1's certification-anchor decision: SAA isn't mandatory to sit, but its
  objective domains are a solid checklist for "did Phase 4 actually cover the ground."
- Domains (current SAA-C03 blueprint): Design Resilient Architectures, Design
  High-Performing Architectures, Design Secure Applications, Design Cost-Optimized
  Architectures — map each to the days that covered it (resilience→ASG/Multi-AZ,
  performance→CloudFront/caching, security→IAM/SG/NACL, cost→budgets/S3
  lifecycle/rightsizing).
- Exam style: scenario questions ("a company needs X, which service...") rather than
  pure recall — today's drill mimics that format deliberately.

### B. Common SAA scenario patterns (20 min)
- "Static website, global users, cost-sensitive" → S3 + CloudFront (Day 99/101).
- "Decouple two services, handle bursts" → SQS between producer/consumer (Day 102).
- "Database needs to survive an AZ failure" → RDS Multi-AZ (mentioned Day 100, not
  built — note the gap honestly).
- "Least-privilege cross-account access" → IAM roles + `sts:AssumeRole` (Day 93/103).
- "Reduce NAT Gateway cost for AWS API calls from private subnets" → VPC Gateway
  Endpoint (Day 97) — a frequently tested cost-and-architecture crossover question.

### C. Resume checkpoints — why now (10 min)
- Recall the README's job-readiness track: checkpoints at Day 111 and Day 148. This is
  the first one — right after the phase's biggest, most demo-able artifact (Day 110's
  live pipeline).
- A resume checkpoint isn't a full rewrite — it's adding **quantifiable, specific**
  lines while the work is fresh (exact numbers/tools beat vague verbs).

### D. What "good" resume bullets look like (15 min)
- Formula: action verb + what was built + technology specifics + outcome/scale.
  Weak: "Worked with AWS and Kubernetes." Strong: "Deployed containerized Python
  service to AWS ECS Fargate behind an ALB with Route 53 + ACM TLS, provisioned
  entirely via a 4-module Terraform stack, deployed by a GitHub Actions pipeline with
  automated smoke tests."
- Portfolio links matter as much as bullets for a fresher — the GitHub repo (public
  since Day 33) with a clear README and pipeline diagram (Day 110's `docs/`) does more
  work than a paragraph.

## Lab (2h)

### Part 1 — SAA-style timed drill (50 min)
1. Write (or pull from a free practice-question source) 15 scenario-style questions
   covering the four domains from Theory A; answer them timed, ~90 sec/question,
   without notes.
2. Self-grade against the day-by-day mapping in Theory B; for every miss, name the
   exact Day N lab that covers the gap and note it as a re-read target.
3. Explicitly flag any topic the course hasn't hands-on covered yet (e.g. Multi-AZ RDS
   failover, Direct Connect, Snowball) — these are legitimate "exam-only, not
   course-built" gaps; don't pretend otherwise.

### Part 2 — Resume checkpoint (50 min)
4. Pull up the current resume (or start the "Experience/Projects" section if this is
   the first pass). Draft 4–6 bullets covering: Linux/Bash foundation (P1), CI/CD +
   containerization (P2), Kubernetes + Helm + Terraform (P3), and AWS end-to-end deploy
   (P4/Day 110) — one strong bullet per phase, using the formula from Theory D.
5. Add a "Projects" line linking the public GitHub repo, with a one-line description
   pulling from Day 110's `docs/pipeline-e2e.md` diagram.
6. Cross-check every claim against what was actually built — no bullet should describe
   something not present in the repo (an interviewer will ask to see it).

### Part 3 — Portfolio polish pass (20 min)
7. Confirm the repo's root README links to: the pipeline diagram, the Terraform module
   README (Day 108), and the security/WAR audit notes (Day 109) — a reviewer should be
   able to navigate the whole story from the README alone.
8. `git log --oneline | wc -l` and skim recent commit messages — confirm they read like
   a coherent build history, not "wip" spam (tidy up the last few if needed, without
   rewriting published history).

**Definition of done:** 15-question timed drill completed and self-graded · gap list
written with honest exam-only-vs-course-built distinctions · resume has 4–6
phase-mapped bullets using the action+tech+outcome formula · README navigable end-to-end
from a stranger's first click.
