# Day 29 — RHCSA-Style Mock Skills Day (Days 1–27)

Phase 1 · follows Day 28 (Review). Format: timed skills assessment across users,
storage, systemd, SELinux, networking — no new theory today. Distro: RHEL/Fedora/
CentOS.

---

## Recall warm-up (5 min)
1. What are the four topic domains being tested today (users/storage/systemd/
   networking-and-SELinux)?
2. Which day covered LVM extend order (LV then filesystem)?
3. Which day covered `semanage fcontext` + `restorecon`?
4. Which day introduced systemd timers?
5. Which day covered `set -euo pipefail`?

## Format
This mirrors an RHCSA exam session: timed, no notes for the first pass, self-graded
after. Set a timer for 90 minutes for the tasks below, work through them in order, then
use the remaining 30 minutes to check your own work against the definition of done and
re-attempt anything that failed.

## Timed tasks (90 min total, roughly 15 min per task)

### Task 1 — Users & permissions (15 min)
Create a user `rhcsa_mock` with a home directory and `/bin/bash` shell, add them to a
new group `mockgrp`, set a password, and configure `chage` so their password expires
in 60 days. Create `/srv/mockdata` owned by `root:mockgrp`, mode 2770 (SGID), and
confirm `rhcsa_mock` can create files there that inherit the group.

### Task 2 — Storage (15 min)
Using a spare disk or loopback file, create a partition, format it xfs, and mount it
persistently at `/mnt/mockstorage` via UUID in `/etc/fstab` with the `nofail` option.
Verify with `mount -a` before considering it done.

### Task 3 — LVM (15 min)
Create a volume group `mock_vg` from a PV, carve out a 300M logical volume
`mock_lv`, format it ext4, mount it at `/mnt/mocklv`, then extend it by 200M and grow
the filesystem live with `resize2fs`.

### Task 4 — systemd (15 min)
Write a `.service` unit that runs `/usr/bin/date >> /tmp/mock_date.log` as a oneshot,
paired with a `.timer` unit that fires every 5 minutes. Enable and start the timer,
confirm with `systemctl list-timers`, and trigger one run manually to confirm the log
file grows.

### Task 5 — Networking & firewalld (15 min)
Given a subnet you calculate by hand (e.g. split `192.168.50.0/24` into 4 `/26`s),
identify the network/broadcast/usable range for the 3rd subnet. Then open port
`8443/tcp` in firewalld persistently and confirm with `firewall-cmd --list-ports`.

### Task 6 — SELinux (15 min)
Create `/srv/mockweb` with a test `index.html`, point nginx's `root` at it, and fix any
resulting 403 using the correct `semanage fcontext` + `restorecon` sequence (not
`chcon`) — verify with `curl` that it serves 200.

## Self-grading checklist
- [ ] Task 1: user/group/perms all verified with `id`, `ls -l`, `chage -l`
- [ ] Task 2: `df -h` and `cat /etc/fstab` confirm persistent mount
- [ ] Task 3: `lvs` shows extended size, `df -h` confirms filesystem grew
- [ ] Task 4: `systemctl list-timers` shows the mock timer, log file has entries
- [ ] Task 5: subnet math correct (verify with `ipcalc`), port confirmed open
- [ ] Task 6: `curl` returns 200, fix used fcontext+restorecon not chcon

## Debrief
For any task not completed within its 15-minute window, note which specific command or
concept caused the delay — that's your real Day 1–27 gap list. Feed those gaps into
tonight's NotebookLM session as a targeted deep-dive prompt: "Explain <topic> at the
level of a senior engineer interviewing me — push past the docs summary into failure
modes and internals."

**Definition of done:** all 6 tasks attempted within their time boxes · self-grading
checklist completed honestly · gap list written down for tonight's NotebookLM
deep-dive.
