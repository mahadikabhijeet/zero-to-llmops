## Theory (1h)

### A. grep fundamentals (15 min)
- `grep <pattern> <file>` searches lines matching a pattern; exit code 0 = found,
  1 = not found, 2 = error (feeds into `&&`/`||` chains from Day 2).
- Key flags: `-r` (recursive), `-i` (case-insensitive), `-n` (line numbers), `-v`
  (invert match), `-c` (count matches), `-l` (filenames only), `-w` (whole word),
  `-A/-B/-C N` (lines after/before/around context).
- `-E` (extended regex, ERE) vs default basic regex (BRE) — ERE needed for `+`, `?`,
  `|`, `()` without backslash-escaping. `egrep` = `grep -E` (legacy alias).

### B. Regex anchors and classes (20 min)
- Anchors: `^` (start of line), `$` (end of line). `^$` matches blank lines.
- Character classes: `[abc]` (any of a/b/c), `[^abc]` (none of), `[a-z]`, `[0-9]`,
  POSIX classes `[[:digit:]]`, `[[:alpha:]]`, `[[:space:]]`.
- `.` matches any single character; escape a literal dot as `\.`.
- Alternation (ERE): `cat|dog` matches either. Grouping: `(ab)+`.

### C. Quantifiers (15 min)
- BRE: `*` (zero or more of preceding) is the only native quantifier; `\+`, `\?`,
  `\{n,m\}` need escaping.
- ERE (`-E`): `*` (0+), `+` (1+), `?` (0 or 1), `{n}`, `{n,}`, `{n,m}` — all unescaped.
- Greedy by default; regex engines here don't support lazy quantifiers (that's Perl/PCRE
  territory — `grep -P` exists on some systems but skip for now).

### D. Practical patterns (10 min)
- IP-ish match: `grep -E '[0-9]{1,3}(\.[0-9]{1,3}){3}'` (not RFC-perfect, good enough
  for log scanning).
- Comments/blanks strip: `grep -Ev '^\s*(#|$)'` — a pattern you'll reuse constantly when
  reading config files.

## Lab (2h)

### Part 1 — grep basics (25 min)
1. `grep -i "error" /var/log/messages` (or `journalctl -b --no-pager > /tmp/boot.log`
   then `grep -i error /tmp/boot.log` if `/var/log/messages` doesn't exist on your
   distro). Count with `-c`.
2. `grep -n "root" /etc/passwd` — note the line number.
3. `grep -v "^#" /etc/ssh/sshd_config | grep -v "^$"` — active (non-comment,
   non-blank) config lines only. This is the `-Ev '^\s*(#|$)'` pattern in two steps.
4. `grep -rl "bash" /etc/passwd /etc/shadow 2>/dev/null` — which files contain "bash"?

### Part 2 — anchors and classes (30 min)
5. `grep -E '^root' /etc/passwd` vs `grep -E 'root$' /etc/passwd` — compare results.
6. `grep -E '^[a-z]{3,}:' /etc/passwd | head` — usernames of 3+ lowercase letters.
7. `grep -E '[0-9]{4}' /etc/passwd` — any UIDs/GIDs with 4+ digit runs.
8. `echo -e "line1\n\nline3" > blanks.txt; grep -n '^$' blanks.txt` — find the blank
   line by anchor pair.

### Part 3 — quantifiers and alternation (30 min)
9. `grep -E 'nologin|/bin/false' /etc/passwd` — all locked-shell accounts.
10. `grep -E '^(root|svc_fresher|fresher01):' /etc/passwd` — three specific accounts
    via alternation + anchor.
11. Build the loose IP pattern from Theory D against a sample: `echo "server 10.0.0.5
    up" | grep -E '[0-9]{1,3}(\.[0-9]{1,3}){3}'`.
12. Compare BRE vs ERE on the same idea: `grep 'ro*t' /etc/passwd` (BRE, native `*`)
    vs `grep -E 'ro+t' /etc/passwd` (ERE, `+` needs `-E`).

### Part 4 — journald + grep combo (35 min)
13. `journalctl -b --no-pager | grep -iE 'error|fail(ed)?|warn(ing)?' | wc -l` — rough
    boot health score.
14. `journalctl -b -u systemd-journald --no-pager | grep -vE '^\s*(#|$)'` — confirm
    the comment/blank-strip pattern works even though journald output rarely has
    comments (sanity check the pattern is harmless when it doesn't apply).
15. Save a "grep cheatsheet" file: `~/lab05/grep-cheatsheet.txt` with 8 of today's
    commands and one-line explanations each — you'll want this on Day 6.

**Definition of done:** comfortable telling BRE from ERE at a glance · wrote and ran
at least 3 anchor patterns and 3 quantifier patterns correctly · produced a working
"strip comments and blanks" one-liner · cheatsheet file saved.
