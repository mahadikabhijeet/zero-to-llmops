## Theory (1h)

### A. Modules and pip (10 min)
- `import module_name` (standard library, always available) vs third-party packages
  installed via `pip install <pkg>` into your active venv (Day 25). `import os`,
  `import sys`, `import json`, `import subprocess` — all standard library, zero
  install needed.
- `pip list` (what's installed in the active venv), `pip freeze > requirements.txt`
  (pin exact versions — the file other people/CI use to reproduce your environment,
  relevant again in Phase 2's CI/CD work).

### B. argparse (15 min)
- The proper way to build a CLI, replacing bash's `getopts` (Day 24) with something
  richer: auto-generated `--help`, typed arguments, required vs optional.
  ```python
  import argparse
  parser = argparse.ArgumentParser(description="System snapshot tool")
  parser.add_argument("-o", "--output", default="report.json", help="output file path")
  parser.add_argument("-v", "--verbose", action="store_true", help="verbose output")
  args = parser.parse_args()
  ```
  `args.output`, `args.verbose` — clean attribute access instead of manual `$1`/`$2`
  parsing.

### C. os and pathlib (20 min)
- `os` module: `os.getcwd()`, `os.environ.get("HOME")`, `os.listdir(path)`,
  `os.path.exists(path)`, `os.getloadavg()` (1/5/15-min load averages — direct Python
  access to what `uptime` shows).
- `pathlib` is the modern, object-oriented alternative to `os.path` string
  manipulation: `from pathlib import Path; p = Path("/opt/fresher_project"); p.exists()`,
  `p / "logs" / "boot_errors.log"` (path joining via `/` operator — genuinely more
  readable than `os.path.join`), `p.glob("*.log")` (like bash globbing, Day 2).
- `shutil.disk_usage(path)` returns `(total, used, free)` in bytes for the filesystem
  containing `path` — the Python equivalent of `df`.

### D. subprocess — Python as a bash upgrade (15 min)
- `subprocess.run(["cmd", "arg1"], capture_output=True, text=True)` returns an object
  with `.stdout`, `.stderr`, `.returncode` — this is how Python scripts call out to
  system tools (`systemctl`, `journalctl`) when there's no pure-Python equivalent,
  exactly as used in Day 25/26's service-check scripts.
- Prefer a list of args (`["ls", "-la", path]`) over `shell=True` with a single string
  — avoids shell-injection risk and quoting headaches entirely (the Python parallel to
  bash's quoting discipline from Day 22).
- `check=True` raises `CalledProcessError` automatically on non-zero exit — Python's
  version of bash's `set -e` for that one call.

### Part 3 — Incremental project: sys_report.py v0 (60 min)
Build `/opt/fresher_project/sys_report.py` — a pure-standard-library snapshot tool
(deliberately dependency-free so it runs anywhere without `pip install`):
6. ```python
   #!/usr/bin/env python3
   import argparse
   import json
   import os
   import shutil
   import subprocess
   from datetime import datetime, timezone

   def get_cpu_load():
       load1, load5, load15 = os.getloadavg()
       return {"load1": load1, "load5": load5, "load15": load15}

   def get_memory():
       meminfo = {}
       with open("/proc/meminfo") as f:
           for line in f:
               key, val = line.split(":", 1)
               meminfo[key] = int(val.strip().split()[0])  # kB
       total = meminfo["MemTotal"]
       free = meminfo["MemAvailable"]
       used = total - free
       return {"total_kb": total, "used_kb": used, "available_kb": free}

   def get_disk(path="/"):
       total, used, free = shutil.disk_usage(path)
       return {"total_bytes": total, "used_bytes": used, "free_bytes": free}

   def get_top_service_errors():
       result = subprocess.run(
           ["journalctl", "-b", "-p", "err", "--no-pager"],
           capture_output=True, text=True
       )
       lines = result.stdout.strip().splitlines()
       return {"error_line_count": len(lines)}

   def build_report():
       return {
           "timestamp": datetime.now(timezone.utc).isoformat(),
           "hostname": os.uname().nodename,
           "cpu_load": get_cpu_load(),
           "memory": get_memory(),
           "disk_root": get_disk("/"),
           "boot_errors": get_top_service_errors(),
       }

   def main():
       parser = argparse.ArgumentParser(description="Fresher project system snapshot")
       parser.add_argument("-o", "--output", default="sys_report.json")
       parser.add_argument("-v", "--verbose", action="store_true")
       args = parser.parse_args()

       report = build_report()
       with open(args.output, "w") as f:
           json.dump(report, f, indent=2)

       if args.verbose:
           print(json.dumps(report, indent=2))
       else:
           print(f"Report written to {args.output}")

   if __name__ == "__main__":
       main()
   ```
7. `chmod +x sys_report.py`, run: `./sys_report.py -v` — confirm valid JSON prints and
   the file is written. `cat sys_report.json | python3 -m json.tool` to pretty-verify.
8. Cross-check values: compare `memory.total_kb` against `free -h`'s total (converted),
   `disk_root` against `df -h /`, `cpu_load` against `uptime`.
9. Run it as `svc_fresher` to confirm permissions are fine:
   `sudo -u svc_fresher python3 /opt/fresher_project/sys_report.py -o
   /opt/fresher_project/logs/sys_report.json`.

**Definition of done:** `sys_report.py` runs standalone with `-v`/`-o` flags via
argparse, produces valid JSON with CPU load, memory, disk, and boot-error-count
sections, values cross-checked against `uptime`/`free -h`/`df -h`, and runs cleanly as
`svc_fresher`.
