A · Multi-user by design

What a user is

  • Own home directory, own files, own permissions
  • username — friendly label · UID — the number underneath
B · The power account

Root and sudo

  • root — can do anything, no restrictions
  • Living as root full-time = one typo can wipe something critical
  • sudo <command> — borrow root's power, one command at a time
  • Rule: read a sudo command twice before Enter
C · A term that finally lands

The "root filesystem"

  • The actual disk mounted at / — the same tree you navigate daily
  • "Root" here = the / you know, not the root user
  • Same word, two meanings — context tells you which
D · How much wakes up

System targets

  • multi-user.target — full system, no desktop — most real servers
  • graphical.target — multi-user + desktop/mouse — your laptop, probably
  • This is why CLI comfort (Day 0b) wasn't optional
