A · The basic split

Hardware vs software

  • Hardware — anything you could drop on your foot: CPU, RAM, disk, keyboard/screen
  • Software — instructions on disk telling hardware what to do
  • System software (the OS) vs application software (browser, game, spreadsheet)
hardware = car (engine, wheels) · software = the driver
B · The traffic cop

What an OS does

  • Programs never touch hardware directly — they ask the OS
  • OS decides: who gets the CPU next, who gets memory, who reads a file, in what order
  • No traffic cop → every program fights every other program → the machine falls over
B · The OS's four jobs

Process · Memory · File · Device

  • Process — running many programs "at once" by switching fast between them
  • Memory — private RAM per program, so one bug can't corrupt another program
  • File — organizes data into files/folders; you never track physical disk location
  • Device — one common way to talk to keyboard/screen/disk/network
Windows, macOS, Android, iOS — same four jobs, different style
C · Linux

Kernel vs distro

  • Linux = a kernel (Linus Torvalds, 1991) — free, open source
  • Distro = kernel + tools + package manager + defaults, packaged for humans
  • Fedora, RHEL, Ubuntu, Debian — all distros, same kernel underneath
C · Why this course

Why RHEL/Fedora

  • Enterprise standard — most company Linux servers run RHEL or its relatives
  • Certification path — RHCSA/RHCE, later in this course, recruiters recognize it
  • Package family — dnf/rpm, learn once, use everywhere
D · The fork in the road

GUI vs CLI

  • GUI — windows, icons, mouse — friendly, slow to repeat, hard to automate
  • CLI — typed commands — faster once learned, and scriptable
  • Scriptable = the seed of automation = the point of DevOps
  • Most real servers have no screen, no mouse — CLI is the only way in

Five things to hold onto

  • Hardware = touchable · Software = instructions

  • Linux = kernel · distro = kernel + tools (Fedora, RHEL)
  • CLI over GUI: faster, scriptable, what real servers give you
