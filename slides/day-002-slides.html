A · Anatomy of the command line

Terminal, shell & getting help

  • Terminal = the window · Shell = bash, reads commands · Console = the screen
  • Shape: command -options arguments — short -l / long --all
  • The #1 skill: getting help. man, and its sections: 1 user · 5 file formats · 8 admin — man 5 passwd ≠ man passwd
  • --help · info · type/which · man -k keyword (apropos)
man -k directory | head  ·  type bash  ·  ls --help | head
B · Filesystem hierarchy & paths

Everything is a file · one tree from /

  • /etc config · /var logs & changing data · /usr installed software
  • /opt third-party — our project lives here · /home · /root · /tmp
  • /proc & /sys — the kernel's live state shown as files (ties to Day 1)
  • Absolute path starts at / · Relative starts from here — . here · .. up one · ~ home · - previous dir
ls -l /  ·  cd /var/log && cd - && pwd
C · Core file tools — look & change

Inspect & manipulate

  • pwd where am I · cd move · ls -l -a -h -t -r list
  • file — what is this really? · stat — deep detail
  • cp -r -p · mv (move/rename) · mkdir -p · touch
  • ln — hard link (same data) vs symlink (pointer) · rm -r — respect it, no undo
mkdir -p ~/lab02demo && touch ~/lab02demo/a.txt && ls -l ~/lab02demo
C · Core file tools — view & find

cat, tail -f & find

  • cat dump · less pager (/ n q) · head/tail top & bottom
  • tail -f — the ops engineer's heartbeat · wc counts
  • find — searches live · by name, type, size, mtime · -exec
  • locate — fast, reads a database, but can be stale — find for truth, locate for speed
find /etc -name "*.conf" -mtime -30 | head
D · The core idea of the day

I/O redirection

  • Three streams: stdin (0) · stdout (1) · stderr (2) — "file descriptors"
  • > write (wipes) · >> append · 2> errors only
  • 2>&1 merge errors into output · &> shortcut · < read stdin from file
  • /dev/null — the black hole; send unwanted output here
ls /etc /nonexistent > out.txt 2> err.txt
D · Joining tools

Pipes & chaining

  • | — stdout of one → stdin of next (the Unix philosophy)
  • tee — split a stream: watch and save
  • ; always · && if success · || if fail · exit code echo $?
  • Globbing * ? [a-z] · always quote "$var" (Day 3)
journalctl -b | grep -i error | wc -l
