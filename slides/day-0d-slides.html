A · Full address

Absolute paths

  • Always starts with / — the root
  • Means the same thing no matter where you currently stand
  • Longer to type, always reliable
/home/student/notes/day1/hello.txt
B · From where you stand

Relative paths

  • Does not start with /
  • Directions from your current working directory — what pwd shows
  • Yesterday's notes/day1/hello.txt was relative the whole time
C · Four shortcuts

. .. ~ -

  • . here · .. up one level
  • ~ your home, always absolute
  • - (with cd -) the previous directory you were in
Live experiment

Same path, two locations

  • cd / && ls home — relative, works from root
  • ls /home — absolute, works from anywhere
  • cd /tmp && ls home — fails — this IS the lesson
Move deliberately

cd .. · cd . · cd ~ · cd -

  • cd ~/practice/notes/day1 → cd .. → cd ..
  • cd . — nothing changes, prove it with pwd
  • cd ~ then cd - toggle until automatic
Get lost, get found

The safety net

  • Chain relative moves without checking pwd — guess where you land
  • pwd always tells you where you are
  • cd ~ always gets you home, no matter how lost
