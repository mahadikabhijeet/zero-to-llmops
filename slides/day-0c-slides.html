A · The big idea

Everything is a file

  • Documents, devices, even kernel info — all files
  • One consistent way to interact with very different things
  • A directory is a special file that holds references to other files
B · One tree, starting at /

The big branches

  • /home your files · /etc config · /var changing data (logs)
  • /tmp scratch · /usr installed software · /opt third-party
  • /bin essential commands — several you already used live here
ls /
C · New commands

Make & look

  • mkdir make a directory · touch create empty file
  • ls -l detail: perms, size, modified time
  • cat print a file's contents · rm remove — no undo
Live — walk the tree

Just looking first

  • ls / · ls /home · ls /etc | head -20
  • pwd — confirm you're safely in your own home space
Lab — build your own tree

mkdir → touch → echo → cat

  • mkdir practice && cd practice
  • mkdir notes && mkdir notes/day1
  • touch notes/day1/hello.txt
  • echo "my first file" > notes/day1/hello.txt then cat it back
Remove, carefully

rm — respect it

  • touch a scratch file, then rm it immediately — lowest stakes
  • Before any real rm: "could I get this back?" → no
  • That pause is the entire safety net
