A · Get the words right

Terminal · Shell · Command

  • Terminal = the window · Shell = bash, reads what you type
  • Shape: command -options arguments
  • A command is just a program's name — the shell finds it on disk and runs it
ls -l /home → command · option · argument
B · The #1 skill

Asking for help

  • man <command> — full manual page
  • <command> --help — quick summary
  • Ctrl+C — cancel something stuck
  • Rule: man it before you ask the trainer
man ls · ls --help | head -20
C · Six safe commands

Own these today

  • whoami · date · pwd
  • ls · echo <text> · clear
  • None of these six can break anything
Live — the prompt

Read it before you type

  • username@hostname:~$ — who you are, roughly where you are
  • Get used to glancing at it constantly
A taste of variables

echo $USER

  • $USER gets substituted with your username
  • The shell can substitute things in, not just print literal text
  • Full lesson on variables comes much later
echo $USER
Practice

Break something small, on purpose

  • Type lls instead of ls
  • "command not found" = the shell searched honestly, found no match
  • Not the machine breaking — completely safe to see
