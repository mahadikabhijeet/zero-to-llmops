A · The user/group model

UID, GID & the account files

  • Every process runs as a UID + primary GID + supplementary groups — like an ID card + department + other doors it opens
  • UID 0 = root · 1–999 system/service · 1000+ human users (cutoffs in /etc/login.defs)
  • /etc/passwd: user:x:UID:GID:GECOS:home:shell — x means "look in shadow"
  • /etc/shadow — hash + aging fields, root-only readable · /etc/group — group:x:GID:members
id  ·  whoami  ·  groups  ·  cat /etc/passwd | column -t -s:
B · Managing users & groups — create & modify

useradd, groupadd, usermod

  • useradd -m -s /bin/bash -c "comment" name — -m makes the home dir · groupadd name
  • usermod -aG group user — always -a with -G, like adding a keycard door
  • Bare -G (no -a) replaces every supplementary group — you can silently lose wheel
  • usermod -s /sbin/nologin user — for service accounts, never an interactive login
B · Managing users & groups — passwords, delete & inspect

passwd, chage, userdel, getent

  • passwd user sets/changes password · chage -l user aging report · chage -M 90 user max age
  • userdel -r user — -r also removes the home dir, no undo
  • getent passwd user / getent group group — works via nsswitch, not just local files
getent passwd $USER  ·  sudo cat /etc/shadow | head -5  ·  chage -l $USER
C · The core idea of the day

su vs sudo vs sudoers

  • su - user — become them entirely, needs their password, full login shell
  • sudo cmd — run one command as another user, needs your own password — a signed permission slip
  • /etc/sudoers — never edit directly, always visudo (syntax-checks before saving)
  • user ALL=(ALL) ALL · %wheel ALL=(ALL) ALL — wheel = sudo on RHEL/Fedora · sudo -l · sudo -u user cmd
cat /etc/group | grep wheel  ·  sudo visudo  ·  sudo -l
D · Password policy

PAM, login.defs & locking

  • PAM (/etc/pam.d/) — the bouncer enforcing policy at login/auth time
  • /etc/login.defs — PASS_MAX_DAYS, PASS_MIN_LEN, UID_MIN/UID_MAX
  • passwd -l/-u user (or usermod -L/-U) — lock/unlock without deleting
cat /etc/login.defs | grep -E "PASS_MAX_DAYS|PASS_MIN_LEN|UID_MIN|UID_MAX"
