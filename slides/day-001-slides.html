A · What Linux actually is

Kernel vs OS vs distro

  • Kernel — one program: hardware, processes, memory, files (Linus Torvalds, 1991)
  • Distro (RHEL/Fedora) = kernel + GNU userland + package manager + defaults
  • Layers: hardware → kernel (kernel space/user space) → shell → apps
uname -a && cat /etc/os-release && hostnamectl
B1 · Stage 1 & 2

Firmware & GRUB2

  • Firmware (BIOS/UEFI) lives on the motherboard — POST, then hand off
  • GRUB2 reads /boot/grub2/grub.cfg, shows the boot menu
  • Loads the chosen kernel image + initramfs into memory, gets out of the way
B2 · Stage 3

initramfs — the bridge

  • Catch-22: kernel needs drivers to mount root, drivers live on that root
  • initramfs = temporary root filesystem in RAM with just enough drivers
  • Mounts the real root, then gets thrown away — cross it once
B3 · Stage 4 & 5

Kernel init → PID 1

  • Kernel drops initramfs, mounts the real root filesystem
  • Execs the first userspace program — always gets PID 1
  • On modern RHEL/Fedora, PID 1 = systemd — parent of everything else
ps -p 1 -o pid,comm
B4 · Profiling boot

systemd-analyze

  • systemd-analyze — total boot time
  • systemd-analyze blame — slowest units, ranked
  • systemd-analyze critical-chain — the dependency chain that delayed it
systemd-analyze && systemd-analyze blame | head -20
C1 · systemd basics

Units & targets

  • Everything is a unit: .service, .target, .timer, .mount...
  • multi-user.target — text-only, networked, what real servers run
  • graphical.target — multi-user + desktop, sits on top of it
systemctl list-units --type=target && systemctl get-default
C2 · systemctl

Two different questions

  • Loaded (boot-time) → enable/disable — persists across reboots
  • Active (right now) → start/stop/restart — immediate only
  • systemctl status shows both at once
systemctl status sshd
C3 · The flight recorder

journald & journalctl

  • Native, structured binary, one unified timeline — kernel to services
  • -b this boot · -u one unit · -p err errors only
  • -f follow live · --since filter by time
journalctl -b | wc -l && journalctl -b -p err --no-pager | tail -10
