A · grep + exit codes

g/re/p — globally search a regex, print

  • grep 'PAT' FILE — always single-quote the pattern, or the shell eats it
  • Exit codes are three-way: 0 found · 1 ran fine, found nothing · 2 grep itself failed
  • "found nothing" ≠ "error" — that's why grep composes with Day 2's && / ||
  • grep -q = quiet, exit code only → the "is this already configured?" idiom
grep 'root' /etc/passwd; echo $?  ·  grep -q 'wheel' /etc/group && echo exists
A2 · the flags worth muscle memory

Nine flags do 95% of the work

  • -i ignore case (logs have Error/ERROR/error) · -n line numbers · -w whole word (root ≠ chroot)
  • -v invert — the noise-stripper · -c count instead of lines · -l filenames only
  • -r recurse a tree · -A/-B/-C N context (the line before the error is the useful one)
  • -o print only the matched part — your regex debugger
grep -in root /etc/passwd  ·  grep -vc nologin /etc/passwd  ·  grep -in -C2 fail /tmp/boot.log
B · anchors & classes

Say where, then say what

  • Anchors match a position, not a character: ^ start · $ end · ^$ = a blank line
  • In /etc/passwd, ^root = "username is root", bash$ = "login shell is bash"
  • Classes: [abc] · [^abc] = NOT (caret inside brackets = negate, outside = start-of-line)
  • POSIX [[:digit:]] [[:alpha:]] [[:space:]] — locale-safe & self-documenting · a bare . matches ANY char — escape it \.
grep '^root' /etc/passwd  ·  grep -n '^$' /tmp/blanks.txt  ·  echo 10x0y0z5 | grep '10.0.0.5'
C · quantifiers · BRE vs ERE

How many — and which dialect

  • * 0+ · + 1+ · ? 0-or-1 · {3} · {2,5} · {3,} — they attach to the one thing before them
  • BRE (plain grep) needs \+ \? \{ \} \( \) \| · ERE (-E) doesn't — the escaping is inverted
  • The trap: grep 'ro+t' throws no error — it silently hunts a literal plus sign. Default to -E.
  • Alternation cat|dog · grouping (ab)+ · egrep = legacy grep -E · greedy only (no lazy — that's PCRE)
grep -E 'nologin|/bin/false' /etc/passwd  ·  echo -e "ab\nabab" | grep -E '^(ab){2,}$'
D · the two keepers

Patterns you'll reuse for the rest of your career

  • Find IPs in a log: [0-9]{1,3}(\.[0-9]{1,3}){3} — built from a group + an escaped dot + {3}
  • Caveat: matches 999.999.999.999 too — right trade for log scanning
  • Strip comments & blanks: grep -Ev '^\s*(#|$)' — 150-line config → the dozen lines that matter
  • \s is a GNU extension (fine on RHEL/Fedora/Ubuntu) · portable form is [[:space:]]*
ip a | grep -oE '[0-9]{1,3}(\.[0-9]{1,3}){3}'  ·  grep -Ev '^\s*(#|$)' /etc/ssh/sshd_config
