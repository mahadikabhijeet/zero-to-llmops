A · rwx and octal

Read any ls -l like a sentence

  • Three classes — owner (u), group (g), other (o) — three bits each: r w x
  • On a directory: x = enter/traverse · r = list · w = create/delete inside
  • Octal: r=4, w=2, x=1, summed per class — rwxr-xr-- = 754
  • chmod 750 (absolute) · chmod u+x,g-w (symbolic) · chown user:group · chgrp
ls -l /etc/passwd /etc/shadow  ·  touch demo; ls -l demo  ·  chmod 750 demo
B · umask

Why new files come out 644

  • The mask subtracted from the max: 666 for files, 777 for dirs (files never get x)
  • Default umask 022 → new file 644, new dir 755
  • umask shows it · umask 027 → 640 / 750 (this session only)
  • Persist: ~/.bashrc (you) · /etc/profile or /etc/bashrc (system-wide)
umask  ·  umask 027; touch f1; mkdir d1; ls -l f1; ls -ld d1  ·  umask 022
C · Special bits — part 1

SUID — run as the owner

  • Three bits on top of the nine: SUID, SGID, sticky — they solve what rwx can't
  • SUID: an executable runs with the file owner's privileges, not the caller's
  • Classic: /usr/bin/passwd is SUID-root — that's how you write root-only /etc/shadow
  • Shows as s in owner's x slot: -rwsr-xr-x · octal 4000 · chmod 4755 / u+s · powerful → set rarely
ls -l $(which passwd)
C · Special bits — part 2

SGID & the sticky bit

  • SGID on a directory: new files inherit the directory's group, not the creator's — shared team dirs
  • This is how /opt/fresher_project/logs will stay devops-trainees. Octal 2000 · chmod 2775 / g+s
  • Sticky bit on a dir: only the file's owner (or root) can delete/rename — even if world-writable
  • Classic: /tmp — shows as t: drwxrwxrwt · octal 1000 · chmod 1777 / +t
ls -ld /tmp  ·  ls -ld /var/tmp
D · ACLs and chattr

When one owner + one group isn't enough

  • Plain rwx = exactly one owner, one group. Need to grant one extra user? ACLs.
  • getfacl file · setfacl -m u:priya:rx file (grant) · setfacl -x u:priya file · setfacl -b file (strip)
  • An ACL shows as a trailing + in ls -l: -rw-r--r--+ — don't miss it
  • chattr +i file — immutable, not even root can modify/delete until -i · lsattr to view
touch acltest; chmod 640 acltest  ·  setfacl -m u:fresher01:r acltest  ·  getfacl acltest
