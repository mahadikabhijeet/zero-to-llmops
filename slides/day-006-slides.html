A · sed — substitution

Stream editor: read a line, change it, print it

  • s/pattern/replacement/ — first match per LINE only. Add g for all: s/foo/bar/g
  • The slash isn't sacred — s#/usr/bin#/opt# beats escaping every slash
  • Capture with -E + parentheses, refer back as \1 \2: sed -E 's/(user)([0-9]+)/\2-\1/'
  • It streams — never loads the file — so a 10 GB log costs nothing
echo "bash bash bash" | sed 's/bash/sh/'  ·  … | sed 's/bash/sh/g'
A2 · addresses & the danger flag

Where to act — and -i has no undo

  • Addresses: '3d' line · '2,4d' range · '/nologin/d' pattern-as-address
  • -n kills auto-print, then p prints what you pick: sed -n '/start/,/end/p' pulls one stack trace out of a huge log
  • sed -i writes to disk. No undo, no confirmation. Always -i.bak
  • Habit above the habit: run it without -i first, eyeball it, then commit
sed -E 's/:bash$/:zsh/' f | grep zsh  →  sed -i.bak -E 's/:bash$/:zsh/' f
B · awk — fields, patterns, actions

Not a command — a tiny language

  • awk 'pattern { action }' — no pattern = every line · no action = print. awk '/root/' ≈ grep
  • $1 $2 … fields · $0 whole line · NF field count (so $NF = last field) · NR line number · -F: sets the separator
  • BEGIN{} runs once before, END{} once after — awk 'END{print NR}' = wc -l
  • The pattern can be arithmetic — $3 >= 1000. Grep can never ask that. Variables auto-start at 0, so {sum+=$3} just works
awk -F: '$3>=1000 && $3<65534 {print $1,$3}' /etc/passwd  ·  awk -F: '{sum+=$3} END{print sum}'
C · the classics + THE idiom

Four small tools, one pipeline to memorize

  • sort is alphabetical — -n or "10" sorts before "9" · -r · -k N · -t:
  • uniq only sees ADJACENT duplicates — unsorted input makes it silently lie. Sort first. Every time.
  • cut -d: -f1,3 (single delimiters) · tr 'a-z' 'A-Z' / tr -d (characters) · paste (side by side)
  • sort | uniq -c | sort -rn = frequency count, most common first. The most-typed pipeline in ops.
awk -F: '{print $7}' /etc/passwd | sort | uniq -c | sort -rn
D · which tool?

grep selects · sed rewrites · awk computes

  • grep when the answer is "these lines" — selection, no transformation
  • sed for surgery on the text of a line: swap a string, delete by pattern, pull a range
  • awk the moment you say field, column, compare, count, or sum
  • They overlap; nobody marks you down. Pick the one that reads clearly to whoever reads it next — that's you, in six months
awk -F: '$7 ~ /nologin/ {n++} END{print n}' — the only one asking the precise question
